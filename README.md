# SoundSeek

Локальная гибридная интеллектуальная система индексации аудиотеки и
мультимодального поиска. Проект выполняется на CPU и не использует облачные
API: все модели работают на машине пользователя.

## Что умеет система

- инкрементально индексировать папку `data/tracks/` (новые, изменённые и
  удалённые файлы);
- искать по названию, исполнителю, альбому, имени файла и личным заметкам;
- искать по текстовому описанию звучания через CLAP;
- искать по фрагменту аудио или напеванию: CLAP-тембр и мелодический
  контур (pyin + CENS-хрома + subsequence DTW);
- искать по строкам песен: лексически и семантически через
  `intfloat/multilingual-e5-small`;
- разбирать запросы с жанрами, настроениями, отрицаниями, годами и
  исполнителем;
- применять онтологические правила и объяснять каждый результат;
- распознавать вокал через Demucs + Whisper и сохранять статус обработки;
- показывать карту CLAP-эмбеддингов (PCA) и собирать плейлист по настроению.

## Требования

- Python 3.11–3.12 (проверено на 3.12.3);
- 16 ГБ ОЗУ; дискретный GPU не требуется;
- FFmpeg в `PATH` (нужен для Whisper и Demucs);
- около 3–4 ГБ свободного места под кэш моделей.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

Проверьте FFmpeg:

```powershell
ffmpeg -version
```

Если FFmpeg не установлен, установите его через WinGet:

```powershell
winget install Gyan.FFmpeg
```

## Запуск

```powershell
.\.venv\Scripts\python.exe web_app\app.py
```

Интерфейс откроется на `http://127.0.0.1:7860`.

При первом запуске скачивается CLAP. Мультиязычная текстовая модель
`intfloat/multilingual-e5-small` используется, если она уже есть в кэше
Hugging Face. Чтобы разрешить её автоматическую загрузку:

```powershell
$env:SOUNDSEEK_ALLOW_MODEL_DOWNLOAD = "1"
.\.venv\Scripts\python.exe web_app\app.py
```

Без этой переменной система использует модель из кэша, а при её отсутствии
откатывается на `all-MiniLM-L6-v2`, чтобы запуск не зависел от сети.

## Индексация

Основной сценарий — добавить файлы через вкладку «Библиотека». Программа
копирует их в `data/tracks/` и выполняет инкрементальную синхронизацию.

Из командной строки:

```powershell
.\.venv\Scripts\python.exe check_scripts\check_indexer_light.py
```

Лёгкая индексация считает CLAP-эмбеддинг по 10-секундным окнам,
распределённым по всей длительности трека, читает теги, обложку, встроенный
текст и классифицирует тип контента, жанр и настроение. Покрытие всего файла
важно для поиска по фрагменту: характерный мотив может находиться в начале
или в конце, а не только в середине. Число окон ограничено
`SOUNDSEEK_INDEX_MAX_WINDOWS` (по умолчанию 72), чтобы длинные файлы не
замедляли индексацию неконтролируемо. Для музыкальных треков дополнительно
сохраняются мелодический контур (96 точек, полутоны) и CENS-хрома по среднему
30-секундному фрагменту; они используются каналом поиска по напеванию.

Тяжёлое обогащение (Demucs + Whisper) запускается кнопкой в библиотеке или:

```powershell
.\.venv\Scripts\python.exe check_scripts\check_enrich.py
```

Статусы `done`, `error`, `skipped` сохраняются в базе, поэтому после
перезапуска уже обработанные треки не запускаются повторно.

Версия аудиопризнаков — `4`. Если библиотека была проиндексирована более
ранней версией, выполните «Обновить библиотеку» с включённым
«Переиндексировать всё»: старые 30-секундные эмбеддинги будут заменены
полнотрековыми, ручные правки и распознанные тексты сохранятся.

## Поиск

```powershell
.\.venv\Scripts\python.exe check_scripts\check_search.py
```

Примеры запросов:

- `lonely day` — точное метаданное + текст;
- `весёлый панк` — жанр + настроение;
- `рок, но не панк` — положительный жанр и отрицание;
- `trap` — близкий `rap`, но без ложного срабатывания на подстроку;
- `piano` — CLAP по описанию;
- `2010-е` — десятилетие по годам из тегов;
- `без вокала` — только треки с подтверждённым отсутствием вокала.
  Неизвестный вокал намеренно не считается инструменталом;
- `тренировка`, `на повтор` — поиск по личным заметкам, сохранённым в
  карточке трека.

## Архитектура

```text
soundseek_core/
  audio.py          загрузка и детерминированная нарезка аудио
  embeddings.py     CLAP и мультиязычный текстовый эмбеддер
  classifier.py     zero-shot классификация и кэш промптов
  enrichment.py     Demucs + Whisper + текстовый эмбеддинг
  indexer.py        оркестрация индексации и синхронизации
  db.py             FAISS, блокировки, атомарное сохранение
  models.py         Track, FileTags, DerivedData, ParsedQuery, SearchHit
  ontology.py       онтология, морфология, иерархия
  query_parser.py   разбор запроса и отрицаний
  rules.py          предметные правила и объяснения
  melody.py         pyin-контур, CENS-хрома, DTW-сходство
  search/
    metadata.py     лексический канал метаданных
    lyrics.py       лексический и семантический канал текста
    notes.py        канал личных заметок
    semantic.py     CLAP-каналы
    melody.py       канал поиска по мелодии
    fusion.py       взвешенное слияние и RRF tie-breaker
    engine.py       оркестратор гибридного поиска
  visualization.py  карта CLAP-эмбеддингов (PCA + SVG)
  playlist.py       генерация плейлиста по настроению
web_app/
  app.py            сборка Gradio-интерфейса
  worker.py         фоновая очередь обогащения
  presenters.py     форматирование результатов
  styles.py         общие стили и прокручиваемое окно библиотеки
tests/              unit- и интеграционные тесты без скачивания моделей
check_scripts/      диагностические сценарии
experiments/        ASR-эксперимент и оценка поиска
docs/               анализ и проектная документация
```

Подробное описание алгоритмов и калибровки приведено в
`docs/implementation.md`.

## Отличия от первой версии

- CLAP больше не использует случайный `rand_trunc`: детерминированные окна
  по всей длительности трека дают воспроизводимый эмбеддинг (косинус между
  повторами равен 1.0).
- Жанр в правилах берётся из `derived.genre`, а не из сырого тега
  `Punk;Rock`.
- Метаданные ищутся по полям, а не по полному пути; слова `music`, `video`,
  `official` не повышают все треки.
- Лирический канал подключён к поиску и использует мультиязычную модель.
- Личные заметки ищутся отдельным лексическим каналом по всей библиотеке;
  заметка также показывается в карточке результата.
- Таблица библиотеки прокручивается внутри отдельного окна, поэтому форма
  редактирования остаётся доступной без прокрутки всей страницы.
- Отрицание «не панк» исключает `punk_rock` и его поджанры, но не
  `heavy_metal`.
- Жанровый фильтр направленный: запрос `rock` покрывает `hard_rock`, а
  `punk` не покрывает соседний `indie_rock`.
- Оценки каналов нормируются и сливаются, а не складываются в разных
  масштабах. Для запросов без текстового ядра (`90-е`, `без вокала`,
  `не панк`) добавляется отдельный канал структурированных кандидатов.
- FAISS-база защищена `RLock`, файлы сохраняются через временные копии,
  статусы обогащения персистентны.
- Ручные правки метаданных переживают повторную индексацию: поля
  помечаются в `manual_fields`.
- Стабильные ID строятся по относительному пути (`sha1`), старые stem-ID
  мигрируют при синхронизации.
- Появились тесты, проверяющие регрессии `lonely day`, `trap`, `весёлый панк`,
  `рок, но не панк`, десятилетия и строгие фильтры года/вокала.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты не загружают CLAP/Whisper: классификатор и эмбеддеры подменяются
лёгкими заглушками, поэтому прогон занимает несколько секунд. Сейчас в
наборе 60 тестов, включая мелодический канал, миграцию старых pickle-баз,
поиск по заметкам и сохранение ручных правок и текстов при повторной
обработке.

## Эксперименты

ASR-эксперимент сравнивает Whisper `base`/`small` на исходном миксе и на
вокальной дорожке после Demucs:

```powershell
.\.venv\Scripts\python.exe experiments\run_experiment.py
```

Интерпретация результатов и таблица для отчёта: `docs/asr_interpretation.md`.

Оценка поиска считает precision@k, recall@k и MRR, а также ablation-анализ
каналов `metadata`, `clap`, `lyrics` и `full`:

```powershell
.\.venv\Scripts\python.exe experiments\evaluate_search.py --top-k 3
```

Проверка воспроизводимости CLAP и классификации:

```powershell
.\.venv\Scripts\python.exe experiments\evaluate_determinism.py
```

Результаты сохраняются в `experiments/results/`. На текущей небольшой
аудиотеке `full` даёт MRR 1.0 при `top_k=3`, а косинус повторных
CLAP-эмбеддингов равен 1.0; это проверка регрессий, а не полноценный
бенчмарк.

## Ограничения

- Поиск по напеванию реализован как экспериментальный мелодический канал:
  `pyin` на смешанной полифонической записи не выделяет ноты идеально, а
  DTW сравнивает контур, а не транскрипцию. Для чистого напева канал
  работает заметно лучше, чем для шумного фрагмента микса.
- CLAP и Whisper чувствительны к качеству записи; на русском языке WER
  выше, чем на английском.
- Жанровая классификация — zero-shot по промптам онтологии; она не заменяет
  экспертную разметку. Настроение классифицируется менее надёжно, чем жанр,
  поэтому ручное редактирование предусмотрено в интерфейсе.
- Фильтры года и вокала строгие: треки без года или с непроверенным
  вокалом не считаются соответствующими. Это сделано, чтобы не выдавать
  неподтверждённые факты; для массовой проверки используйте обогащение.
- Мультиязычная текстовая модель требует отдельной загрузки; без неё
  используется английский fallback, и качество русских текстов снижается.
