# SoundSeek

Локальная гибридная интеллектуальная система автоматической индексации
и мультимодального поиска в аудиотеке.

## Возможности

- поиск треков по текстовому описанию;
- поиск по названию и метаданным;
- поиск по напеванию мелодии;
- автоматическая индексация новых файлов;
- извлечение текста из вокальных партий;
- объяснение результатов поиска.

## Стек

- Python 3.11+
- CLAP, Whisper, Demucs, Sentence-Transformers (все на CPU)
- FAISS для векторного поиска
- Gradio для интерфейса

## Структура

- `soundseek_core/` — ядро системы
- `web_app/` — веб-интерфейс
- `tests/` — тесты
- `data/` — тестовая аудиотека
- `models/` — веса моделей
