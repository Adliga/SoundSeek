# Интерпретация результатов эксперимента

## Что говорят цифры

Смотрю на таблицу и вижу три закономерности и одну аномалию. Начну с закономерностей.

**Закономерность 1. Demucs помогает, но не всегда одинаково.**

| Трек | Модель | WER на миксе | WER на вокале | Изменение |
|------|--------|--------------|---------------|-----------|
| lonely_day | base | 0.4341 | 0.3101 | **−28.6 %** |
| lonely_day | small | 0.4264 | 0.2248 | **−47.3 %** |
| korol_i_shut | base | 0.5300 | 0.5438 | **+2.6 %** (хуже) |
| korol_i_shut | small | 0.4147 | 0.3641 | **−12.2 %** |

Для английского трека Demucs даёт **стабильное улучшение** в обеих моделях — от 29 до 47 %. Для русского — картина сложнее: с `base` качество слегка **упало**, с `small` улучшилось, но скромно. Причина, скорее всего, в характере сепарации: панк-вокал Короля и Шута с агрессивной подачей Demucs мог «заглушить», и Whisper `base` не справился с более тихим и «неживым» голосом. `small` оказался устойчивее.

**Закономерность 2. Модель `small` заметно точнее, но дороже по времени.**

| Условие | Среднее WER `base` | Среднее WER `small` | Улучшение |
|---------|---------------------|----------------------|-----------|
| mix | 0.4821 | 0.4206 | −12.8 % |
| vocals | 0.4270 | 0.2945 | −31.0 % |

Модель `small` выигрывает везде, но особенно — на чистых вокальных дорожках. При этом среднее время обработки растёт в разы:

| Условие | Время `base`, с | Время `small`, с | Во сколько раз медленнее |
|---------|------------------|-------------------|---------------------------|
| mix | 16.4 | 43.2 | ×2.6 |
| vocals | 23.3 | 72.9 | ×3.1 |

**Закономерность 3. Лучшая конфигурация — `small` + Demucs.**

Средний WER по двум трекам:
- base + mix: **0.482**
- base + vocals: **0.427**
- small + mix: **0.421**
- small + vocals: **0.295**

`small` + `vocals` почти **в 1.6 раза точнее** базовой конфигурации.

**Аномалия. Странный CER у `lonely_day mix small`.**

WER = 0.4264, CER = 0.3890. Обычно CER в 2–3 раза ниже WER, потому что ошибки на уровне символов частичны. Здесь они почти равны — это значит, что модель либо выдала совершенно другие слова (а не близкие по написанию), либо галлюцинировала фрагменты. Стоит открыть `experiments/results/lonely_day__mix__small.txt` и посмотреть глазами — возможно, `small` на шумном миксе «придумал» лишние строки. Это нормальный побочный эффект больших моделей Whisper на плохом входе.

### 2. График

Столбчатая диаграмма: по оси X — четыре конфигурации (`base+mix`, `base+vocals`, `small+mix`, `small+vocals`), по оси Y — WER, две группы столбцов — по трекам. Строится в Excel или matplotlib за 5 минут:

```python
import matplotlib.pyplot as plt
import numpy as np

configs = ["base + mix", "base + vocals", "small + mix", "small + vocals"]
lonely = [0.4341, 0.3101, 0.4264, 0.2248]
korol = [0.5300, 0.5438, 0.4147, 0.3641]

x = np.arange(len(configs))
w = 0.35
plt.bar(x - w/2, lonely, w, label="Lonely Day (EN)")
plt.bar(x + w/2, korol, w, label="Двое против всех (RU)")
plt.xticks(x, configs)
plt.ylabel("WER")
plt.title("Влияние Demucs и размера модели Whisper на качество ASR")
plt.legend()
plt.grid(axis="y", alpha=0.3)
plt.tight_layout()
plt.savefig("experiments/results/wer_chart.png", dpi=150)
```

### 3. Текст анализа

В отчёт можно вставить примерно такое:

> Анализ результатов показывает, что применение сепарации вокала (Demucs) снижает WER для английского трека на 28.6% для модели base и на 47.3% для модели small. Для русского трека эффект оказался менее выраженным: при использовании модели base WER незначительно увеличился (+2.6%), что может быть связано с потерей выразительности вокала после сепарации. Модель small показала стабильное улучшение на обоих треках.
>
> Увеличение размера модели с base до small обеспечивает дополнительное снижение WER, однако сопровождается ростом времени обработки в 2.6–3.1 раза. Наиболее точной конфигурацией является комбинация Demucs с моделью Whisper small (средний WER 0.295), тогда как базовая конфигурация без сепарации и с моделью base даёт средний WER 0.482.

### 4. Вывод по выбору конфигурации

> Для основной системы выбрана конфигурация **Demucs + Whisper base**. Она обеспечивает приемлемый компромисс между качеством (WER снижается на 11% относительно baseline без сепарации) и временем индексации (~23 секунды на трек против ~73 секунд у small). Модель small может быть подключена опционально как «режим повышенной точности» для коротких треков или по запросу пользователя.

## Что ещё стоит сделать перед оформлением

1. **Проверьте аномалию** — откройте `lonely_day__mix__small.txt` и сравните с эталоном. Возможно, там лишние строки от галлюцинаций. Если так — это хорошая иллюстрация ограничений ASR на музыкальных миксах, добавьте абзац в отчёт.
2. **Добавьте третий трек** (например, японский PinocchioP) — тогда выводы станут менее «двухточечными» и более убедительными. Достаточно только `base + vocals` и `small + vocals`, чтобы не тратить время на mix.
3. **Уберите дубликаты** — если результаты записываются в JSON каждый раз заново, старые данные перезаписываются. Это нормально, но стоит сделать пару прогонов для воспроизводимости и убедиться, что WER не «прыгает».

Результаты хорошие и полностью пригодны для диплома. Demucs оправдал себя, `small` показал лучшую точность — гипотеза подтвердилась.
